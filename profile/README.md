# ctrlcplusv

**Copy. Paste. Ship.**

We take business models that already work, build our own open source version, and ship it. Open source for fun, hosted for convenience.

## How it works

1. **We pick a proven model.** If people already pay for it, the demand is real.
2. **We build it in the open.** Full source code on GitHub, no features held back.
3. **You can self-host it for free.** Run it on your own server whenever you like.
4. **Or we host it for you.** Updates, backups and uptime handled, so you can skip the setup.

The roadmap comes from GitHub issues. If you want something built, open one.

## Projects

- **[plain-motion](https://github.com/ctrlcplusv-labs/plain-motion)**: beat-synced motion graphics videos in plain TypeScript. No animation libraries, music synthesized in code, rendered with headless Chrome and ffmpeg. MIT licensed.
